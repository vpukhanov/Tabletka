# Tabletka

Medication tracking app with a focus on privacy, deep Android integration and a native idiomatic user interface.

## Used Technologies

- UI: Jetpack Compose, Material 3
- Data: Room

## Engineering Approaches

- Always follow TBD and the red → green → verify loop
- Make Composables atomic, single-purpose and reusable

## Agent Guidance

- Use JDK bundled with Android Studio when running commands like `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew test`
